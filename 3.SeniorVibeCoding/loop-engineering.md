# Loop Engineering

Use these resources as starting points, not as a required reading list.

## Start here

- [Loop engineering — Addy Osmani](https://addyosmani.com/blog/loop-engineering/): a concise introduction to the concept.
- [Different types of engineering](https://www.youtube.com/watch?v=4biXYSNkn9Y): an introductory video suitable for opening the discussion.

## Practical examples

- [Practical loops with Codex](https://www.damiangalarza.com/loops/?utm_source=youtube&utm_medium=video&utm_campaign=codex-loops): written examples of Codex loops.
- [Practical Codex loops video](https://www.youtube.com/watch?v=5dHRqb51fs0): video treatment of the same examples.

## Optional deeper exploration

- [Loop Engineering repository](https://github.com/cobusgreyling/loop-engineering)
- [Loop Engineering quick-start guide](https://github.com/cobusgreyling/loop-engineering/blob/main/docs/QUICKSTART.md)

## Questions for the room

- What triggers the loop?
- What outcome is the agent pursuing?
- How does it verify progress?
- What stops it?
- Which decisions should still require human judgment?
