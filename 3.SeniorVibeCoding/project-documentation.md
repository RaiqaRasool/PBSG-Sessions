## Discussion question

When are six specialized documents helpful, and when are `AGENTS.md` plus a temporary `TASK_PLAN.md` enough?

Consider project size, task duration, number of collaborators, cost of mistakes, and how frequently the documentation will be maintained. More files are useful only when each one has a clear reader and purpose.
