# Before the workshop: desktop app and GitHub connection

You need the desktop app with Codex access and its GitHub plugin. No local Git, terminal, Firecrawl, or Playwright MCP installation is required. Keep START-HERE.md open as the main guide.

The kit also includes CLAUDE.md and GEMINI.md, which point to the shared AGENTS.md. These let alternative assistants use the same project instructions; this setup guide and its GitHub connection steps remain specific to Codex. Other tools' integrations and preview capabilities need their own check.

## A. Open the AI app

1. Use the official quickstart above to install the desktop app for your computer if needed.
2. Sign in with your ChatGPT account and locate Codex. Ask the facilitator if your account does not provide access.
3. Do not start a portfolio chat yet; you will attach the starter folder first in START-HERE Step 3.

Current official docs describe Codex inside the ChatGPT desktop app. If you use a standalone Codex app with different screens, follow its verified equivalent with the facilitator. Do not switch to a terminal or IDE extension for this workshop.

## B. Connect GitHub where the reason is clear

GitHub will hold the website files and publish them. In the desktop app:

1. Open **Plugins**, search for **GitHub**, and open its details.
2. Select the install control (a **+** in the official guide), then follow the connection prompt.
3. When GitHub asks you to sign in, use your personal account. If you have none, use [Sign up](https://github.com/signup), complete email verification, then return to the connection flow. The account guide above explains this in more detail.
4. Review the connection's GitHub App installation on that same account. In the reported rehearsal its name was **Codex Connector**; use the name actually shown by your connection. Authorization to act as you and installation access to repositories are distinct.
5. You may select only the website repository. If you have not created it yet, finish connection and add that repository after Step 7 creates it. Do not grant every repository just to get past setup.
6. Return to START-HERE. The first portfolio chat comes after you select the extracted folder.

**Expected result:** GitHub is installed/connected. This does not yet prove it can write to a repository. Step 7 checks the destination and installation access; the first authorized publication confirms writes.

Do not paste passwords or tokens into chat. Account/app permissions may need your approval. A work-managed account may need an administrator; use a personal account for the workshop if allowed.
