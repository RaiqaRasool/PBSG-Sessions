# Prepared design and personality briefs

These eight briefs are ready to use locally. Participants do not need Firecrawl, screenshots, or access to the original websites to build from them. Original links in DESIGN-OPTIONS.md remain available for optional exploration.

Each brief includes observed visual cues, extracted font evidence, an interpreted personality, explicit implementation choices, résumé presentation, and phone/accessibility rules. It deliberately adapts the inspiration into a focused one-page portfolio.

These are text-based design briefs, not completed HTML templates or exact reproductions. Source screenshots and font files are not bundled. Source-font names are recorded; system fallbacks make the build independent of font downloads. Proposed palettes, dimensions, responsive rules, and motion are labeled as workshop choices. Check the generated website for contrast and readability.

The résumé is evidence, not a required section list. Apply the content-curation rules in AGENTS.md before these design layouts: omit unsupported Projects and other categories, remove résumé-only administrative details, and do not ask for more material just to fill a layout. SAMPLE-RESUME.md is an optional fictional input, not content to blend into a real portfolio.

## AI workflow

1. Resolve the chosen name, number, or listed URL using DESIGN-OPTIONS.md. Read only the corresponding brief plus CONTENT.md and AGENTS.md; there is no need to load every reference.
2. Use the brief directly. Do not refetch the original or prompt for Firecrawl setup. If the participant explicitly wants a current-site comparison, use available tools as optional enhancement.
3. Save the selected source, brief filename, personality interpretation, actual fonts/fallbacks, and adaptations in DESIGN.md.
4. Build the approved content and verify its preview at desktop and phone widths. Follow the public-assets and publishing instructions in AGENTS.md.
5. For an unlisted URL, follow OPTIONAL-REFERENCE.md. A custom reference is an optional extension, not a blocker to building with a prepared option.

Review context: November 1, 2026; prepared briefs have not yet been tested through a complete portfolio build. The original sites may change without changing these saved workshop directions.
