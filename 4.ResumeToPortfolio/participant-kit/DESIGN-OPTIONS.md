# Choose a prepared design and personality

Choose a name or number below. Codex will read the matching prepared file from your starter folder. **No Firecrawl setup or reference-site access is required.** Original website links are for optional exploration; the local briefs already contain visual cues, font evidence and fallbacks, personality, layout, and content-presentation guidance.

These are self-contained, text-based workshop adaptations rather than finished templates or exact replicas. Source screenshots and font files are not bundled. Each brief labels observations, personality interpretations, and implementation choices so AI does not have to invent a direction from a link.

**Choose the look, not the size of someone else's career.** You do not need as much content, a blog, a publication archive, or all the pages shown on these sites. AI will adapt the personality to your own résumé and a focused one-page portfolio. You can add or remove sections later with one sentence.

## What choosing each reference could bring to your site

These are suggested adaptations of observed homepage styling, not promises to copy a whole website. Desktop opening views were visually checked on November 1, 2026. Themes can vary, and mobile layouts, deeper pages, motion, and the final implementation still need checking in the generated portfolio. The saved briefs specify proposed phone and motion behavior without requiring another source-site inspection.

**Want a quick starting point?** Try Seán for soft and expressive, Brittany for structured and professional, or Cassidy for compact and personal. You can select any style regardless of your profession. For a different public URL, follow the optional custom-reference guide after your first build.

**Optional inspiration — [Bruno Simon](https://bruno-simon.com/):** this driving-game portfolio has no prepared brief in the starter kit. Explore it for fun; use [the custom-reference guide](OPTIONAL-REFERENCE.md) if you want to adapt its personality. A complete 3D game is outside the default one-page workshop scope.

You do not need to fill every panel shown on a reference site. Two strong highlights can be enough. If you want, add one sentence such as “Use Seán's soft colors, but keep my page as compact as Cassidy's.” Start with one main reference to keep the first build predictable; mixing details is optional later.

## AI workflow for prepared options

Read [references/README.md](references/README.md) and the one selected brief. Use its supplied implementation values and personality interpretation directly. Do not require Firecrawl, screenshots, source-site access, or participant research. Save source, local brief path, actual font fallbacks, and adaptations in DESIGN.md; then build from CONTENT.md and verify the generated preview.

For an unlisted source or a participant-requested fresh inspection, follow [OPTIONAL-REFERENCE.md](OPTIONAL-REFERENCE.md). Do not silently replace a prepared file with a new scrape.
