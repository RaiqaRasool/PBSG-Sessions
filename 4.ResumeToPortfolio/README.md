# From résumé to portfolio with AI

Codex is the AI coding assistant in the ChatGPT desktop app. You’ll give it your résumé, talk through a design, and ask it to build a website you can open in your browser.

1. **[Start the workshop guide](START-HERE.md)** to prepare your résumé, open a local folder in Codex, and copy the build and update prompts.
2. **[Jump to Codex setup](START-HERE.md#2-open-your-folder-in-codex)** if your résumé is ready. The facilitator will walk through the desktop screens during the session.
3. **[Publish your site if you want a public link](PUBLISH.md)** at `https://YOUR-USERNAME.github.io/`.

## Setup resources

- **Codex** — Install the ChatGPT desktop app and sign in. The facilitator will show how to open your workshop folder. [Desktop quickstart](https://learn.chatgpt.com/docs/quickstart?setup=app) · [OpenAI video introduction](https://www.youtube.com/watch?v=0e-Brv-gS9Q)
- **Visual Studio Code (optional)** — Use this editor if you want to open and edit your website files by hand. [Install VS Code](https://code.visualstudio.com/docs/getstarted/overview) · [Official beginner video](https://www.youtube.com/watch?v=f8_uF_IDV50)
- **Git (optional)** — Git records changes to your files. The workshop’s publishing guide uses GitHub Desktop, which handles Git through buttons. If you want to learn the terminal workflow later, start with [Set up Git](https://docs.github.com/en/get-started/git-basics/set-up-git).
- **GitHub Pages (optional)** — Follow the workshop’s publishing guide first. Use GitHub’s screenshots if you want a visual reference for the Pages settings. [Workshop publishing guide](PUBLISH.md) · [Illustrated GitHub Pages quickstart](https://docs.github.com/en/pages/quickstart)
