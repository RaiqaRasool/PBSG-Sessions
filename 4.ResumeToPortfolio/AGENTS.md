# Workshop repository instructions

- Use START-HERE.md and PUBLISH.md as the sources for the current workshop workflow. Keep the README as a short entry point. Write for participants new to Codex and GitHub.
- Rehearse in a separate local folder. Keep private résumés and reference material out of commits and public sites. Use only résumé-supported claims, confirm public contact details, and visibly label sample-based sites as fictional.
- Keep generated portfolios readable, responsive, and able to open directly in a browser. Use references as inspiration. Keep publishing optional and document the GitHub Pages account-site path at username.github.io.
- Before sharing the guide with attendees, rehearse setup, build, direct browser preview, one revision, and optional publication plus an update.
- Review the diff, stage explicit paths, and make a concise Conventional Commit for each meaningful workshop revision. A local commit does not authorize a push.
