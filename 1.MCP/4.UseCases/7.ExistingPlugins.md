# Existing Plugin: Create a Presentation

This final example shows that you may already have a useful capability available—no custom MCP setup required.

## Google Slides

Use this prompt:

Use @Presentations to create a 4-slide presentation.

Slide 1: MCP in Daily Work
Slide 2: What MCP is
Slide 3: GitHub, Playwright, and MarkItDown use cases
Slide 4: Key takeaways

Keep the slides concise and save the result as:
mcp-demo.pptx

The result is easy to verify: confirm that the file exists, contains four slides, and follows the requested structure.
