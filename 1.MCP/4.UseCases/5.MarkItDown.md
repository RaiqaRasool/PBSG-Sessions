# MarkItDown: Make Difficult Content AI-Friendly

## Why this is useful

Important information often arrives in formats that are awkward to search or analyze. MarkItDown converts that content into Markdown so it can be summarized, compared, and questioned.

```text
PDF ───────┐
PPTX ──────┤
DOCX ──────┤
Excel ─────┤
Image ─────┤ → MarkItDown → Markdown
Audio ─────┤
Web page ──┤
YouTube ───┘
```


## Setup

Start by installing `uv`, then connect MarkItDown to Codex.

### MarkItDown MCP setup for Codex CLI

**1. Install `uv`**

macOS/Linux:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Then verify:

```bash
uv --version
uvx --version
```

`uvx` comes with `uv`.

**2. Add MarkItDown MCP to Codex**

```bash
codex mcp add markitdown -- uvx markitdown-mcp
```

This tells Codex to launch the MarkItDown MCP server using `uvx`.

**3. Verify**

```bash
codex mcp list
```

You should see something like:

```text
markitdown    uvx    markitdown-mcp    enabled
```

You can also inspect it with:

```bash
codex mcp get markitdown
```

**4. Restart Codex**

If Codex is already running, exit that session and start a new one:

```bash
codex
```

The new session should now have the MarkItDown MCP tools available.

**5. Try it**

Choose the example that matches the content you want to analyze.

For a PDF:

```text
Use MarkItDown MCP server to convert this [GlueX_Collab_May2025.pdf](GlueX_Collab_May2025.pdf) to Markdown:

Then summarize the document and extract its key points.
```

For a PowerPoint:

```text
Use MarkItDown to convert:

file:///Users/<username>/Downloads/presentation.pptx

to Markdown and summarize each section.
```

For a web resource:

```text
Use MarkItDown to convert this URL to Markdown:

https://youtu.be/WJhCa12UTsg?si=WTJS0sRIy1wuPxPq

Then give me the main takeaways.
```

### Why `uvx`?

This is worth one sentence in your instructions because attendees may wonder why they just installed another tool:

```text
uvx runs MarkItDown MCP in an isolated Python environment without
requiring you to globally pip-install the package.
```

So you get:

```text
Codex
   ↓
MarkItDown MCP via uvx
   ↓
PDF / PPTX / DOCX / XLSX / HTML / etc.
   ↓
Markdown
   ↓
LLM
```

And unlike the Docker setup, you don't need to mount every directory you want MarkItDown to access.

One security note I'd put in small text on your instructions: **because MarkItDown is running as your local user, only use MCP servers you trust and remember that local MCP processes may have access to files your user can access.**

## What to notice

- Conversion is the bridge, not the final task; the follow-up prompt creates the value.
- The same workflow applies to several file and media formats.
- Local access is powerful, so the trust boundary matters as much as the convenience.
