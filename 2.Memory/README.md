# Agent Memory

This session explores how AI agents keep useful information available within a task and across future tasks. The three notes move from short-term context to durable memory and then to the episodic, semantic, and retrieval systems that make stored information useful.

## Study the session

Read the material in this order:

1. [Short-term memory and context engineering](agent-memory-short-term-context-engineering.md)
2. [Long-term memory and memory engineering](agent-memory-long-term-memory-engineering.md)
3. [Episodic memory, semantic memory, and retrieval](agent-memory-episodic-semantic-retrieval.md)

As you study, focus on four questions:

- Where does each kind of memory live, and how long should it last?
- What information should be remembered, summarized, retrieved, updated, or forgotten?
- How do episodic and semantic memory differ?
- How does an agent choose the right memory for its current context?
